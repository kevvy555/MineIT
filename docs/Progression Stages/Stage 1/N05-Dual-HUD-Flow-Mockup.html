Encoding rules (this mock)

  • Colony row: green when surplus ≥ 0 (increasing / stable), red when declining. Days = ∞d when not declining, else runway.
  • Ship row: green while days left ≥ 10 (or no daily drain → treat as plenty). Red when days < 10. Same stock +prod −use S± string as colony.
  • Card shell stays neutral; trend color is per-row so ship-falling + colony-surplus can both be visible.
  • Ops cards stay capacity-style with S/C text color (good/warn/bad), not flow backgrounds.
  • Independent scene drops every S row.
